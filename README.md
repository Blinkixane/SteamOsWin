# SteamOsWin

> **Work in progress — early development**

SteamOsWin is an experimental open-source project aiming to provide a **console-like Steam gaming experience on Windows**.

The goal is to keep the native Windows gaming stack and compatibility while providing a dedicated Gaming Mode inspired by modern console interfaces.

## Current status

The project is currently under active development.

The current repository contains an already functional prototype that will serve as the baseline for future development.

Expect:

* breaking changes;
* incomplete documentation;
* experimental features;
* limited hardware testing;
* major architectural changes before the first public release.

## Goals

SteamOsWin aims to provide:

* a dedicated Steam Gaming Mode;
* controller-first navigation;
* fast switching between Gaming Mode and normal Windows;
* minimal background resource usage while gaming;
* safe and reversible Windows optimizations;
* multi-monitor and ultrawide support;
* HDR and VRR support where available;
* NVIDIA, AMD and Intel compatibility;
* native Windows game and anti-cheat compatibility;
* robust recovery and rollback mechanisms;
* a simple `Setup.exe` installer.

## Safety

SteamOsWin must never require:

* Windows kernel patching;
* disabling Secure Boot;
* disabling Windows Defender;
* disabling driver signature enforcement;
* permanent destructive Windows debloating.

System changes should be **minimal, reversible and recoverable**.
